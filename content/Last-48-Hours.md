## 3. The 8 grammar rules that appear every time

1. Each / every / either / neither / everyone → **singular verb**
2. The number of → singular; **a number of → plural**
3. Neither…nor / either…or → verb agrees with the **nearer** subject
4. Since + point of time; **for + period**
5. Senior / junior / superior / inferior / married / addicted → **to**
6. Good at · accused of · insist on · consist of · die of · prefer X **to** Y
7. If + past, would + base (2nd); If + had + V3, would have + V3 (3rd)
8. Mind / enjoy / avoid / look forward to / used to / cannot help → **-ing**

**Spelling five:** accommodation · occurrence · maintenance · committee · embarrass.
