A. Keyboard shortcuts (Q1–Q12)

Q1. Ctrl + C is used to: a) Cut b) Copy c) Paste d) Close

Answer: b) Copy

Q2. Ctrl + V is used to: a) Paste b) Copy c) Undo d) Select all

Answer: a) Paste

Q3. Ctrl + X is used to: a) Copy b) Cut c) Paste d) Redo

Answer: b) Cut

Q4. Ctrl + Z is used to: a) Redo b) Undo c) Save d) Print

Answer: b) Undo

Q5. Ctrl + Y is used to: a) Undo b) Redo c) Find d) Replace

Answer: b) Redo

Q6. Ctrl + S is used to: a) Select all b) Save c) Search d) Stop

Answer: b) Save

Q7. Ctrl + P is used to: a) Paste b) Print c) Preview d) Page setup

Answer: b) Print

Q8. Ctrl + F is used to: a) Find b) Format c) File d) Freeze

Answer: a) Find

Q9. Ctrl + A is used to: a) Add b) Select all c) Align d) Apply

Answer: b) Select all

Q10. Which key starts a PowerPoint slideshow from the beginning? a) F2 b) F5 c) F7 d) F12

Answer: b) F5 (Shift + F5 starts from the current slide)

Q11. Which shortcut opens the "Save As" dialog in MS Office? a) F5 b) F7 c) F12 d) Ctrl + S

Answer: c) F12

Q12. Alt + F4 is used to: a) Refresh b) Close the active window c) Open a file d) Rename

Answer: b) Close the active window

B. Computer fundamentals (Q13–Q20)

Q13. 1 kilobyte (KB) equals: a) 1000 bytes b) 1024 bytes c) 1024 bits d) 100 bytes

Answer: b) 1024 bytes

Q14. 1 gigabyte (GB) equals: a) 1000 MB b) 1024 MB c) 1024 KB d) 512 MB

Answer: b) 1024 MB

Q15. The "brain" of a computer is: a) RAM b) Hard disk c) CPU d) Monitor

Answer: c) CPU (Central Processing Unit)

Q16. Which of the following is volatile memory? a) ROM b) RAM c) Hard disk d) Pen drive

Answer: b) RAM — contents are lost when power is off.

Q17. The first generation of computers used: a) Transistors b) Vacuum tubes c) Integrated circuits d) Microprocessors

Answer: b) Vacuum tubes

Q18. The third generation of computers used: a) Vacuum tubes b) Transistors c) Integrated circuits d) Artificial intelligence

Answer: c) Integrated circuits

Q19. Which of the following is an operating system? a) MS Word b) Windows c) Excel d) Chrome

Answer: b) Windows

Q20. Which of the following is system software? a) MS Word b) Operating system c) Photoshop d) WhatsApp

Answer: b) Operating system

C. Networking & internet (Q21–Q26)

Q21. LAN stands for: a) Large Area Network b) Local Area Network c) Linked Access Node d) Long Access Network

Answer: b) Local Area Network

Q22. WAN stands for: a) Wireless Access Network b) Wide Area Network c) Web Area Node d) Wide Access Node

Answer: b) Wide Area Network

Q23. HTTP stands for: a) HyperText Transfer Protocol b) High Transfer Text Program c) Hyperlink Text Transfer Process d) Home Text Transfer Protocol

Answer: a) HyperText Transfer Protocol

Q24. URL stands for: a) Uniform Resource Locator b) Universal Reference Link c) United Resource Language d) Uniform Routing Line

Answer: a) Uniform Resource Locator

Q25. Which device connects a local network to the internet? a) Monitor b) Router c) Printer d) Scanner

Answer: b) Router

Q26. Which of the following is a web browser? a) Google Chrome b) MS Excel c) Windows 11 d) Adobe Photoshop

Answer: a) Google Chrome

D. Security & office applications (Q27–Q30)

Q27. A computer virus is: a) A hardware fault b) A malicious program c) A type of monitor d) A network cable

Answer: b) A malicious program

Q28. Phishing is: a) A method of fishing b) Fraudulently obtaining sensitive information by impersonation c) A type of firewall d) A backup technique

Answer: b) Fraudulently obtaining sensitive information by impersonation

Q29. In MS Excel, which formula adds the values from A1 to A10? a) =ADD(A1:A10) b) =SUM(A1:A10) c) =TOTAL(A1:A10) d) =PLUS(A1:A10)

Answer: b) =SUM(A1:A10)

Q30. The default file extension of an MS Word 2016+ document is: a) .xlsx b) .pptx c) .docx d) .pdf

Answer: c) .docx
